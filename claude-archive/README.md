# claude-archive

Локальный архиватор ваших данных из claude.ai. Запускается только вручную, ничего не отправляет в сеть, удалённого git-репозитория нет. Нужны Python 3 (лаунчер `py`) и Git for Windows.

## Установка

1. Скопируйте содержимое этой папки в `D:\ClaudeArchive` (путь можно изменить в `config.json`).
2. Двойной клик по `Выгрузить.bat`. Если диска D: нет, программа остановится и ничего не создаст.

## Что где лежит

```
D:\ClaudeArchive
  inbox\       сюда кладёте zip экспорта и memory-ГГГГ-ММ-ДД.md/txt
  chats\ГГГГ\  ГГГГ-ММ-ДД_название_id.md и папки <чат>_files\ (артефакты, вложения)
  memory\      memory_ГГГГ-ММ-ДД.md, CURRENT.md, CHANGELOG.md
  processed\   обработанные файлы по датам
  INDEX.md      чаты по месяцам; SEARCH.txt — одна строка на чат
  state.json, log.txt, config.json
```

Чаты, пропавшие из нового экспорта, не удаляются. Если чат в новом экспорте короче, остаётся прежняя версия. Каждая выгрузка — коммит в локальный git, прежние версии можно посмотреть командой `git log -p -- chats/...`. Папки `inbox` и `processed` в git не попадают (там сырые zip).

## Как получить свежие данные

```
ШАГ 1. Запросить экспорт.
  claude.ai → имя/аватар → Settings → Privacy → Export data → подтвердить.
  Если пункт называется иначе — ищи в Settings раздел про Privacy или Data.
  Зачем: кнопки «скачать всё напрямую» нет, экспорт — единственный
  официальный способ получить копию чатов.

ШАГ 2. Дождаться письма.
  Приходит на почту аккаунта Claude, обычно за несколько минут; проверь «Спам».
  Зачем: ссылка на архив приходит только в письме, программа почту не читает.

ШАГ 3. Скачать zip.
  Нажми ссылку в письме, скачай архив и положи в inbox. Распаковывать не нужно.
  Зачем: программа сама распакует и разложит чаты по файлам. Ссылка действует
  ограниченное время — качай сразу.

ШАГ 4. Сохранить память (по желанию).
  В любом чате с Claude напиши: «Выведи всю мою память одним текстом».
  Скопируй ответ в файл memory-ГГГГ-ММ-ДД.md в inbox.
  Зачем: экспорт может не включать память; так в архиве хранится её история
  и видно, что изменилось.

ШАГ 5. Запустить выгрузку.
  Вернись в это окно, выбери пункт 2.
  Зачем: программа разложит чаты, обновит индекс и сохранит версию в git.
```

## Безопасность

Архив содержит конфиденциальные разговоры. Зашифруйте диск или папку:

- **BitLocker (Windows Pro/Enterprise):** Проводник → правый клик по диску D: → «Включить BitLocker» → пароль → сохраните ключ восстановления вне компьютера (не на этом же диске) → «Шифровать весь диск». В Windows Home вместо этого может быть «Шифрование устройства» (Параметры → Конфиденциальность и защита), но обычно оно охватывает только системный диск.
- **Зашифрованный контейнер (любая Windows):** бесплатный VeraCrypt → Create Volume → Encrypted file container → файл, например `D:\Claude.hc`, → после монтирования как отдельная буква диска укажите её в `config.json`.
- Шифрование защищает диск, пока он закрыт. Когда он разблокирован, файлы доступны любой программе.
- Сырые zip в `processed\` содержат всё то же самое; после проверки результата их можно удалить вручную.
