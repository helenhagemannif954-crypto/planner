# claude-archive

Локальный архиватор ваших данных из claude.ai. Запускается только вручную, ничего не отправляет в сеть, удалённого git-репозитория нет. Нужны Python 3 (лаунчер `py`) и Git for Windows.

## Установка

1. Скопируйте содержимое этой папки в `D:\ClaudeArchive` (путь можно изменить в `config.json`).
2. Двойной клик по `Выгрузить.bat` открывает меню; перетаскивание на него файла `manifest-….json` сразу запускает скачивание и выгрузку. Если диска D: нет, программа остановится и ничего не создаст.

## Как это работает

Экспорт claude.ai приходит набором zip-файлов по категориям (conversations, memories, projects, light_metadata, frames, claude_code_cloud, voice_sessions; у каждой может быть несколько частей) и файлом-манифестом `manifest-….json` со списком файлов и ссылок. Программа **не качает сама**: ссылки одноразовые и требуют входа в аккаунт. Она открывает их по одной в вашем браузере, ждёт появления файла в папке загрузок (путь спрашивается один раз и сохраняется в `config.json`), переносит файл в `inbox`, проверяет набор по манифесту и раскладывает данные.

- Ссылки живут 24 часа от `created_at`; просроченные программа не открывает.
- Одну ссылку программа открывает не более одного раза. Если файл не скачался, нужен новый экспорт.
- Неполный набор обрабатывается только после вашего явного «д».
- Файлы с тем же SHA-256 повторно не обрабатываются.

## Что где лежит

```
D:\ClaudeArchive
  inbox\          манифест и zip набора (и необязательные memory-ГГГГ-ММ-ДД.md/txt)
  chats\ГГГГ\     ГГГГ-ММ-ДД_название_id.md и папки <чат>_files\
  memory\         ГГГГ-ММ-ДД\ (как есть + memory.md), CURRENT.md, CHANGELOG.md
  projects\       ГГГГ-ММ-ДД\ (md по проектам, _as_is\ — файлы как в экспорте)
  raw\            ГГГГ-ММ-ДД\<категория>\ — всё остальное как есть (+ читаемые md, если формат понятен)
  processed\      обработанные файлы по датам
  INDEX.md, SEARCH.txt, state.json, log.txt, config.json
```

Чаты, пропавшие из нового экспорта, не удаляются; если чат в новом экспорте короче, остаётся прежняя версия. Каждая выгрузка — коммит в локальный git (`git log -p -- chats/...`). Папки `inbox` и `processed` в git не попадают (там сырые zip).

## Как получить свежие данные

```
ШАГ 1. Запросить экспорт.
  claude.ai → Settings → Privacy → Export data → подтвердить.
  (Если пункт называется иначе — ищи раздел про Privacy или Data.)
  Зачем: кнопки «скачать всё напрямую» нет, экспорт — единственный
  официальный способ получить копию чатов.

ШАГ 2. Из письма скачай маленький файл manifest-….json.
  Письмо приходит на почту аккаунта Claude, обычно за несколько минут;
  проверь «Спам». Манифест качается одним кликом.
  Зачем: это список всех файлов экспорта со ссылками на них; по нему
  программа проверяет, что скачано всё. Ссылки действуют 24 часа.

ШАГ 3. Перетащи этот файл на «Выгрузить.bat».
  Программа сама откроет ссылки в браузере, дождётся загрузки, разложит
  всё по архиву и сохранит версию в git.
  Зачем: ссылки одноразовые и требуют входа в аккаунт, поэтому качает
  твой браузер, а программа только открывает их по одной и ждёт файлы.
```

## Безопасность

Архив содержит конфиденциальные разговоры. Зашифруйте диск или папку:

- **BitLocker (Windows Pro/Enterprise):** Проводник → правый клик по диску D: → «Включить BitLocker» → пароль → сохраните ключ восстановления вне компьютера (не на этом же диске) → «Шифровать весь диск». В Windows Home вместо этого может быть «Шифрование устройства» (Параметры → Конфиденциальность и защита), но обычно оно охватывает только системный диск.
- **Зашифрованный контейнер (любая Windows):** бесплатный VeraCrypt → Create Volume → Encrypted file container → файл, например `D:\Claude.hc`; после монтирования как отдельная буква диска укажите её в `config.json`.
- Шифрование защищает диск, пока он закрыт. Когда он разблокирован, файлы доступны любой программе.
- Загрузки браузера: пока файлы не перенесены в `inbox`, они лежат в папке «Загрузки» — переносит их программа. Сырые zip в `processed\` содержат то же, что и архив; после проверки результата их можно удалить вручную.
