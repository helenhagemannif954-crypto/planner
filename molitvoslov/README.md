# Молитвослов Древней Церкви — устройство

Приложение: `docs/molitvoslov/` (публикуется GitHub Pages по адресу
`https://helenhagemannif954-crypto.github.io/planner/molitvoslov/`).
Документы, исходники переводов, инструменты и тесты — здесь, в `molitvoslov/`.

| Файл | Что в нём |
|---|---|
| `DECISIONS.md` | все неочевидные решения и их причины |
| `STYLE.md` | правила перевода и авторских строк, пробник |
| `EXCLUDED.md` | что не вошло и почему |
| `REPORT.md` | что сделано, что осталось, ссылка |
| `source/psalms/*.txt` | исходники перевода Псалтири |
| `source/plan/*.txt` | план последовательного чтения с вопросами |
| `source/checked-psalms.txt` | какие псалмы вычитаны стих за стихом (партиями) |
| `tools/` | сборка и проверка содержимого |
| `tests/` | тесты Playwright |

## Приложение

Без сборки: `index.html`, `css/app.css`, ES-модули в `js/`, содержимое в `content/*.json`,
шрифт Literata в `fonts/`, `sw.js` (офлайн), `manifest.json`.

| Модуль | Назначение |
|---|---|
| `js/app.js` | экраны, маршруты (`#now`, `#orders`, `#themes`, `#theme/<id>`, `#fav`, `#names`, `#settings`, `#read/<вид>/<id>`, `#pray/<чин>/<состояние>[/<тема>]`), настройки, установка |
| `js/office.js` | сборка чина из блоков: условия дня, объём, выбор без повторов, круг Псалтири, чтение дня |
| `js/render.js` | вывод блоков чина: текст, псалом, чтение (двойное, медленное), тишина с таймером, помянник |
| `js/calendar.js` | юлианская пасхалия, седмицы, посты, темы седмиц, выбор чина по времени |
| `js/content.js` | загрузка JSON и индексы |
| `js/store.js` | `localStorage`: настройки, помянник, избранное, указатели, журнал неповторяемости |
| `js/ics.js` | файл `.ics` с часами молитвы для календаря телефона |
| `js/util.js` | мелочи: даты, хэш, разбиение на фразы |

Для проверки можно подменить «сейчас»: `?now=2026-04-12T07:30`.

## Форматы содержимого (`docs/molitvoslov/content/`)

У каждого текста есть `source` (откуда), `century` (когда), `translation_note` (как переведено,
что сокращено). Строки текста — массив; пустая строка `""` — пауза, новая строфа.
Авторские строки приложения помечены `source: "составлено для приложения"` (или поясняют,
из каких стихов составлены).

### `psalms.json`

Собирается из `source/psalms/*.txt` (см. ниже).

```json
{ "psalms": [ { "n": 62, "heb": "63", "title": "Псалом Давида…",
    "verses": [ { "n": 2, "l": ["Боже, Боже мой,", "к Тебе я пробуждаюсь до рассвета."] } ],
    "parts": [[1, 24], [25, 48]], "translation_note": "…" } ] }
```

Нумерация — греческая, как в Синодальном переводе; стих с надписанием (если в Синодальном он
отдельный) в `verses` не входит, а лежит в `title`. `parts` — деление длинного псалма для чтения
по кругу; если его нет, псалом до 30 стихов читается целиком, а длиннее — частями по ~22 стиха.

### `odes.json`

`odes`: `{ id, title, source, verses: [{n, l}] }`; `week`: какие песни в какой день недели
(`"0"` — воскресенье; если песен две — чередуются по неделям).

### `prayers.json`

- `fixed` — постоянные тексты по ключу (`entry-morning`, `gloria`, `phos`, `lord`, …).
- `pool` — сменяемые молитвы: `id`, `title`, `kind` (`ancient` — древняя молитва,
  `word` — короткое слово отцов для часов, `scripture` — стихи Писания, `composed` — авторская),
  `moments` (`morning`, `evening`, `sleep`, `night`, `hard`, `intercession`, `meal-before`,
  `meal-after`, `hour3`, `hour6`, `hour9`), `themes`, необязательные `states`, `seasons`, `days`
  (0–6).
- `lines` — авторские связующие строки: приглашение к своим словам (`own`), предание
  (`entrust`), строка после чтения (`afterReading`), отпусты (`dismissal`), шаги пересмотра
  дня (`review`), заголовки часов (`hours`), строки помянника (`names`), строки для детей.

### `themes.json`

`themes`: `{ id, title, line, verse, questions[], prayerThemes[], psalms[], own }`;
`order` — порядок тем рядовых седмиц; `seasonal` — темы постов и Пятидесятницы.

### `scripture.json`

Текст Писания сюда **не пишется руками** — его вписывает `tools/fill_scripture.py` по
Синодальному переводу.

- `plan` — последовательные чтения: `id`, `ref`, `title`, `key` (ключевой стих `глава:стих`),
  `q` (вопросы), `book`, `chapter`, `verses: [[глава, стих, текст]]`.
- `special.byPascha` (`when` — день от Пасхи), `special.feasts` — чтения особых дней.
- `readingPools` — отрывки для состояния «Тяжело» (утешение).
- `pools` — ссылки на отдельные стихи (часы, изнеможение, ночь, дети, благословения);
  их текст — в `verses`, стихи псалмов берутся из нашей Псалтири.
- `books` — полные названия книг.

### `needs.json`

«Псалмы на всякую нужду»: `groups: [{ id, title, items: [{ n, line }] }]`, `title`, `intro`. В группе
3–8 псалмов. В раздел идут только вычитанные псалмы, их список —
`molitvoslov/source/checked-psalms.txt` (строка на партию вычитки). Слова в «ёлочках» в `line` —
дословно из Псалтири приложения. Оба правила проверяет `check_content.py`.

### `orders.json`

`offices` — чины. У чина: `id`, `title`, `when`, `subtitle`, `states` (`false` — без выбора
состояния) и `plans`: списки блоков для состояний `normal`, `weary`, `hard`.

Общие поля блока: `t` — тип; `vol` — для каких объёмов правила (`short`, `normal`, `full`; без
`vol` — для всех); `if` — условие дня или список условий (`penitent`, `fast`, `lent`,
`lentWeekday`, `holyweek`, `sunday`, `saturday`, `paschal`, `pinned`, `unpinned`, `am`, `pm`,
`plain`; `!` перед именем — отрицание); `k` — множитель длительности тишины; `rubric` — заголовок.

| `t` | Что показывает | Поля |
|---|---|---|
| `text` | постоянный текст | `id`; `alt: [{if, id}]` — замена по условию |
| `theme` | тема седмицы (строка над чином) | — |
| `psalm` | псалом | `n` (и `paschal` — другой номер в Пятидесятницу), `from`/`to`; или `circle: true` — следующий отрывок Псалтири по кругу; или `pool` / `fromTheme: true` — выбор из пула без повторов (элемент `ode:<id>` — песнь) |
| `ode` | библейская песнь | `id`, иначе — песнь дня недели |
| `prayer` | молитва из пула | `moment`, `kind`, `state` (`null` — без фильтра по состоянию), `theme`, `themeOnly`, `prefer` |
| `reading` | чтение: текст → вопросы → тишина → второе чтение → строка предания | `pool` (вместо плана), `questions` (сколько вопросов), `double` |
| `intercession` | молитва о других и помянник | `prayer: false`, `departed: false` |
| `own` | приглашение к своим словам и тишина | `set` (`morning`, `hard`, `night`, `theme`) |
| `silence` | тишина с таймером | `k` |
| `lord` | молитва Господня | — |
| `word` | ключевой стих утреннего чтения | `when: "evening"` — вечером, только если утром чтение было показано |
| `dismissal` | отпуст и благословение | `set`, `blessing: false` |
| `review` | пересмотр дня по шагам с короткими паузами | `set` |
| `verse` | стих из пула | `pool` (путь в `scripture.pools`, например `weary.morning`) |
| `remembrance` | память часа и слово отцов | `hour` (3, 6, 9) |
| `line` | одна связующая строка | `set` (путь в `prayers.lines`) |
| `question` | один вопрос и пауза | `set` (массив) или `"theme"` |
| `themeverse` | стих темы седмицы | — |

`pools` — пулы псалмов для блоков `psalm` с `pool`.

## Исходники перевода Псалтири (`source/psalms/*.txt`)

```
# 62                              начало псалма
@1 Псалом Давида…                 надписание — стих 1 (или @1-2; @0 — надписание без номера)
2 Боже, Боже мой, / к Тебе …      стих: номер и строки через « / »
! 62:12 по-гречески …             заметка переводчика (translation_note)
% 1-24, 25-48                     части для чтения по кругу (необязательно)
```

Сборка (из корня репозитория):

```
python3 molitvoslov/tools/build_psalms.py molitvoslov/source/psalms ПУТЬ/К/ru_synod.json docs/molitvoslov/content/psalms.json
```

`ru_synod.json` — Синодальный перевод из репозитория `thiagobodruk/bible` (`json/ru_synod.json`);
по нему сверяется число стихов каждого псалма.

## План чтений (`source/plan/*.txt`)

Файлы читаются по порядку имён. Отрывок:

```
Мк 1:1–8 | Голос в пустыне | 3
? Где во мне пустыня, в которой готовится путь Господу?
? Какие «стези» в моей жизни сейчас кривые?
```

Первая строка: ссылка | название | ключевой стих (номер стиха или `глава:стих`). Строки с `?` —
вопросы (2–3, от первого лица, без форм, выдающих род; слова в «ёлочках» — дословно из
отрывка, это проверяет `check_content.py`). Строки с `//` — комментарии.

```
python3 molitvoslov/tools/fill_scripture.py ПУТЬ/К/ru_synod.json molitvoslov/source/plan/*.txt
```

## Проверки

```
python3 molitvoslov/tools/check_content.py   # ссылки, поля, цитаты псалмов и цитаты в вопросах, длина отрывков
python3 molitvoslov/tools/check_gender.py    # авторские строки, которые могут выдавать род
python3 molitvoslov/tools/sw_version.py      # версия кэша по содержимому файлов — после любой правки
python3 molitvoslov/tools/apply_psalter_review.py ОТЧЁТ.md   # правки рецензента Псалтири (см. tools/psalter-review-prompt.md)
npx playwright test -c molitvoslov/tests/playwright.config.mjs   # экраны, чины, офлайн, установка
```

**Обновления.** Service worker отдаёт файлы из кэша, поэтому правка дойдёт до установленного
приложения, только если сменилась версия кэша в `sw.js`. Её ставит `tools/sw_version.py`
(хэш всех файлов); тест `pwa.spec.mjs` падает, если версию забыли обновить.

Локальный сервер: `node tools/serve.mjs 4174 /planner/` из корня репозитория →
`http://localhost:4174/planner/molitvoslov/`.
